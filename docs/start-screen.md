# Стартовый экран и список станций

## Зачем нужна
Первокурсник должен за один экран понять, что это за квест, с чего начать и какие станции его ждут.

## Пользовательский сценарий
1. Игрок открывает CampusQuest и видит название квеста и краткое описание.
2. Нажимает «Начать квест» — открывается список станций.
3. В списке видит станции, их короткие названия и отметку «пройдено / не пройдено».

## Критерий готовности
- На экране есть название квеста и кнопка «Начать квест».
- Список станций отображается после нажатия кнопки.
- У каждой станции есть название и статус прохождения.

## Риск или вопрос
- Сколько станций показывать на первом экране, чтобы не перегрузить новичка?
