# Проверка ответа

## Зачем нужна
Игрок должен сразу понимать, верный ли ответ он ввёл, и получать баллы за правильный ответ.

## Пользовательский сценарий
1. Игрок вводит ответ в карточке загадки.
2. Нажимает «Проверить».
3. Система сравнивает ответ с эталоном и показывает результат.
4. За верный ответ начисляются баллы; за неверный — сообщение и возможность повторить.

## Критерий готовности
- Верный ответ засчитывается и начисляет баллы.
- Неверный ответ не начисляет баллы и показывает сообщение.
- Можно повторить попытку (если это разрешено правилами).
